## About The Project

<p align="center">
  <img src="public/imgs/screenshot.png" alt="App Screenshot" width="600">
</p>

A single-page Vue.js utility that calculates TNG-era stardates dynamically. Users can adjust both the base year and the calendar date to convert dates into standard 5-digit Star Trek stardates with decimal precision.

### Built With

* [Vue.js](https://vuejs.org/)
* [Vite](https://vite.dev/)
* [Bootstrap](https://getbootstrap.com)
* [Sass](https://sass-lang.com/)

<!-- GETTING STARTED -->
## Getting Started

To get a local copy up and running, follow these steps.

### Prerequisites

Make sure you have Node.js installed (LTS version recommended).
* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/s9yk3r/tng-stardate-calculator.git
   ```
2. Move into the project folder
   ```sh
   cd tng-stardate-calculator
   ```
3. Install dependencies
   ```sh
   npm install
   ```
4. Start the dev server
   ```sh
   npm run dev
   ```
   Vite will print the local URL (usually `http://localhost:5173`) — open it in your browser and you're good to go.

### Build

To generate a production-ready bundle:

```sh
npm run build
```

The output is written to the `dist/` folder and can be deployed to any static hosting service (GitHub Pages, Netlify, Vercel, etc.). To preview the production build locally:

```sh
npm run preview
```
